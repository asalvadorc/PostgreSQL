# Secuencias

Una secuencia genera valores numéricos que podemos utilizar como identificadores. `CREATE SEQUENCE` define su inicio e incremento; `ALTER SEQUENCE` permite reiniciar el contador, y `DROP SEQUENCE` elimina la secuencia.

!!! quote sintaxis "Sintaxis básica"

    <div class="syntax-table-wrap">
    <table class="syntax-table syntax-completa">
    <tbody>
    <tr><td><code>CREATE SEQUENCE [ IF NOT EXISTS ] [esquema.]nombre</code><br/><code>    [ START WITH inicio ]</code><br/><code>    [ INCREMENT BY incremento ];</code></td></tr>
    <tr><td><code>ALTER SEQUENCE [esquema.]nombre</code><br/><code>    RESTART WITH valor;</code></td></tr>
    <tr><td><code>DROP SEQUENCE [ IF EXISTS ] [esquema.]nombre [, ...]</code><br/><code>    [ CASCADE | RESTRICT ];</code></td></tr>
    </tbody></table>
    </div>

    **Opciones**

    **`CREATE SEQUENCE`**

    - `START WITH`: primer valor; por defecto, 1 en una secuencia ascendente.
    - `INCREMENT BY`: salto entre valores; por defecto, 1.

    **`ALTER SEQUENCE`**

    - `RESTART WITH`: establece el próximo valor.

    **`DROP SEQUENCE`**

    - `IF EXISTS`: evita el error si no existe.
    - `RESTRICT`: impide borrar si hay dependencias (por defecto).
    - `CASCADE`: elimina también objetos dependientes.


#### Obtener y consultar valores: NEXTVAL y CURRVAL

- `nextval('nombre_secuencia')`: avanza la secuencia y devuelve el siguiente valor.
- `currval('nombre_secuencia')`: devuelve el último valor obtenido mediante `nextval()` para esa secuencia **en la sesión actual**, sin avanzar el contador. Si todavía no se ha ejecutado `nextval()` para esa secuencia en esa sesión, da error.

`currval()` también funciona si `nextval()` se ha ejecutado automáticamente mediante el `DEFAULT` de una columna al insertar una fila. Los valores generados desde otras sesiones no cambian el resultado de nuestro `currval()`. Realiza las comprobaciones desde el mismo editor SQL, sin desconectarte entre sentencias.

Consulta las [funciones de secuencias de PostgreSQL](https://www.postgresql.org/docs/17/functions-sequence.html).

!!! example practica "Pruébalo: Probar una secuencia"

    Ejecuta las sentencias una a una. Observa los códigos generados antes de eliminar la tabla de demostración.

    ```sql
    CREATE SEQUENCE seq_jugadores_demo START WITH 1000 INCREMENT BY 5;
    CREATE TABLE jugadores_demo (
        id_jugador INTEGER DEFAULT nextval('seq_jugadores_demo') PRIMARY KEY,
        nombre VARCHAR(150)
    );
    INSERT INTO jugadores_demo (nombre) VALUES ('Alex'), ('Noa');
    SELECT * FROM jugadores_demo;

    SELECT currval('seq_jugadores_demo'); -- Devuelve 1005 sin avanzar.
    SELECT nextval('seq_jugadores_demo'); -- Genera y devuelve 1010.
    SELECT currval('seq_jugadores_demo'); -- Sigue devolviendo 1010.

    DROP TABLE jugadores_demo;
    DROP SEQUENCE seq_jugadores_demo;
    ```

Las filas reciben los códigos 1000 y 1005. La llamada posterior a `nextval()` genera 1010, pero no inserta otra fila en la tabla: solo avanza la secuencia. Una secuencia puede tener huecos y no garantiza una numeración consecutiva. En este ejemplo eliminamos primero la tabla y después la secuencia, que son objetos independientes. Otra opción es `INTEGER GENERATED BY DEFAULT AS IDENTITY`.
